# Лика голосом: слушает, отвечает, читает книги

Бесплатный голосовой помощник для Windows: микрофон → распознавание речи локально →
ответ модели через релей → русский голос → колонки. Плюс читалка TXT, EPUB и FB2,
которая запоминает, где остановилась.

## Что нужно

- Windows, Python 3.11 (на `.8` уже стоит).
- Колонки. Микрофон понадобится позже, для голосовых команд.
- Интернет: голос `edge-tts` (бесплатный, Microsoft) и модель через `cloud.nanolika.ru`.

## Установка

```bat
cd C:\Users\nadts\voice-agent
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
```

Ключ аккаунта положить в файл `key.txt` рядом с `agent.py` — одной строкой `nm_...`.

Книги — в папку `books\`: `.txt`, `.fb2`, `.epub`. Имя файла — это название, по нему
Лика ищет книгу голосом.

## Запуск

Двойной щелчок по `lika.bat`: включается музыка и «Идиот», дальше управление клавишами.

```bat
lika.bat        :: музыка и «Идиот», управление горячими клавишами
player.bat      :: пустая консоль, команды пишутся словами
```

## Горячие клавиши

| клавиша | что делает |
| --- | --- |
| пробел | пауза и продолжай |
| `+` / `-` | громкость музыки |
| `M` | музыка включить или выключить |
| `N` | следующий трек |
| `S` | где мы сейчас |
| `Q` | выход |

В заголовке окна видно книгу, абзац, громкость музыки и идёт ли чтение.

## Микшер

Музыка и голос идут по разным каналам. Пока Лика говорит или читает книгу, музыка
сама приглушается до четверти громкости, а после — возвращается. Музыка лежит в
`music\` (mp3, ogg, wav) и играет по кругу.

Команды в окне `player.bat`:

- «музыка» — включить; «выключи музыку» — выключить.
- «тише», «громче», «музыка на 20» — громкость.
- «читай идиот» — читать книгу с закладки; «пауза»; «продолжай».
- «что читаешь» — место в книге и громкость музыки.
- «выход» — закрыть.

## Библиотека

Книги лежат в `books\` (TXT, EPUB, FB2). Название для окна и голоса задаётся в
`library.json`:

```json
{ "idiot": "Идиот: Достоевский" }
```

Ключ — имя файла без расширения, значение — как книгу называть.

## Сколько стоит

Чтение книги ничего не стоит: голос `edge-tts` бесплатный, а модель при чтении не
вызывается вовсе. Озвученные куски складываются в `cache\`, поэтому повторное чтение
того же места идёт без обращений к сети.

Разговор с Ликой идёт через релей с дневным запасом аккаунта, отдельной оплаты за
запросы нет.

Скорость речи: `NANOLIKA_RATE` (по умолчанию `-10%`), высота: `NANOLIKA_PITCH`
(по умолчанию `-6Hz`), голос: `NANOLIKA_VOICE`.

## Что говорить

- «Привет, как дела» — обычный разговор.
- «Читай Гарри Поттер» или «Открой книгу …» — начинает читать с закладки.
- «Продолжай», «дальше» — читает дальше.
- «Стоп», «пауза» — замолкает.
- «Что читаешь», «где мы» — говорит место в книге.

## Голос

Выбранный голос: `ru-RU-SvetlanaNeural` с настройками «пониже и помедленнее» —
скорость `-10%`, высота `-6Hz`. Так книга звучит теплее, как чтение на ночь.

Сменить: переменные `NANOLIKA_VOICE` (например `ru-RU-DmitryNeural`), `NANOLIKA_RATE`,
`NANOLIKA_PITCH`.

Сравнение бесплатных движков лежит в `voices-demo\`: Светлана в трёх темпах, Дмитрий,
локальные Piper (Ирина, Денис) и голос переводчика Google. Скрипт сравнения —
`market.py`.

Если нужен «офигенный» голос, следующий шаг — платные ElevenLabs или OpenAI, либо
Yandex SpeechKit с голосом `alena` (та же семья, что у Алисы) по бесплатному гранту.

## Ограничения этого среза

- Голосовые команды пока не работают: микрофон на `.8` (веб-камера C310) даёт почти
  нулевой уровень, разбираемся позже. Всё управление идёт клавишами.
- Слова-будильника «Алиса» нет.
- Камера не подключена: снимок и vision-модель — следующий шаг.
