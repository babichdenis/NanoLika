# Палитра бренда NanoLika

Цель: тёплая, человечная палитра, без розово-сердечной стереотипики. Подчёркивает «как подруга» — тепло, простота, забота.

## Основные цвета

| Назначение | HEX | Роль |
|---|---|---|
| Терракота (акцент/монограмма) | `#C05B3C` | Основной акцент; плитка монограммы NL. Тёплый, душевный. |
| Коралл (искорка) | `#E4795A` | Свободный акцент, символ уюта/«искорки тепла». |
| Персик (фон знака-листа) | `#F3B693` | Мягкий, тёплый фон, придаёт лёгкость. |
| Шалфей (лист) | `#7E9B77` | Природный, спокойный, балансирует тепло. |
| Тёплый крем (буквы монограммы) | `#FBF1E6` | Мягкий контраст с терракотой, не белизна, живее. |

## Текстовые/утилитарные

| Назначение | HEX | Роль |
|---|---|---|
| Глубокий тёплый текст | `#3A2E28` | Основной текст, хорошо читаем на кремовом. |
| Белый | `#FFFFFF` | Для инверсии на тёмном фоне. |

## Правила использования

- **Иконка «Spark»** (искорка): одиночный мягкий 4-лепестковый знак, `#E4795A`, 512×512 PNG с прозрачным фоном. Хорошо читается уменьшенным до 32 px.
- **Иконка «Monogram»** (NL): терракотовая плитка `#C05B3C`, кремовые буквы `#FBF1E6`. Нормальный/жирный начертательный вариант (Avenir Next Bold) для лучшей читаемости в малых размерах.
- **Иконка «Leaf»** (лист в круге): персиковый круг `#F3B693`, шалфей `#7E9B77`, прожилка — просвет персика. Прозрачный фон.
- **Вордмарк «NanoLika»**: слитное написание, N и L заглавные. Тёмный вариант `#3A2E28` для светлого фона; белый `#FFFFFF` для тёмного фона. Ширина 1200 px, прозрачный фон.

## Примечания

- Не использовать розово-сердечную стилистику, блёстки, единорогов.
- Не использовать панд, зверьков, чужие маскоты.
- Палитра тёплая, простая, в основном один-два цвета на иконке.
