# Веб без компьютера: маршрут `/api/*` с релея в рантайм аккаунта

**Статус:** план на ближайшую работу (05.11.2026). Ничего ещё не включено.

## Задача

PWA и веб на `cloud.nanolika.ru/web` сейчас — только экран: страницу отдаёт релей, а
клиент ходит в `/api/*` того же origin. У релея агентской петли нет, поэтому первый же
запрос падает (`Load failed`), и веб работает только пока открыт компьютер с приложением.

Нужно: чтобы веб-клиент для аккаунта попадал в **рантайм на релее** — тот же
`MuseService`, что обслуживает Telegram и MAX. Тогда телефону компьютер не нужен.

## Схема

```
веб/PWA  ──/web/api/*──▶  релей (cloud.nanolika.ru)
                              │  кука nm_session → аккаунт
                              │  короткий runtime-токен
                              ▼
                         рантайм аккаунта (MuseService, :8799)
```

- **Релей** проксирует `/web/api/*` и WebSocket `/web/api/events` в рантайм.
- **Сессия** остаётся на релее: браузер не получает ключей рантайма.
- **Токен рантайма** — короткоживущий, привязан к аккаунту; рантайм проверяет его тем же
  секретом, что и релей (или через `cloud`-ключ аккаунта).

## Шаги

1. **Маршрут для одного аккаунта (владельца).** Релей: `/web/api/{path}` → рантайм бота
   (контейнер `nanolika-bot`, порт 8799). Кука → аккаунт; если аккаунт не тот — 403.
   Проверка: PWA на телефоне открывает чат, пишет, получает ответ при выключенном Mac.
2. **Токен вместо куки в рантайме.** Релей выдаёт короткий токен на аккаунт; рантайм
   принимает только его. Кука в рантайм не передаётся.
3. **Все аккаунты.** Рантайм на аккаунт: сначала один общий процесс бота с изоляцией по
   `customer_scope`, затем пул воркеров (см. разбор архитектора, `NanoLika-cloud-worker-*.md`).
4. **Стриминг.** WebSocket/SSE через тот же прокси, чтобы ответ шёл по мере генерации.

## Что НЕ делать

- Не отдавать браузеру ключ аккаунта или рантайма.
- Не смешивать аккаунты в одном рантайме без `customer_scope` (память, цели, напоминания).
- Не включать это для всех, пока не проверено на владельце.

- Второй аккаунт (тестовый) не видит чаты первого.
