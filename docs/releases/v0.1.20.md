# NanoLika 0.1.20 · Presence

Call your Muse. Steer your coding agents from your pocket. One account, one look, on every device you own.

**NanoLika is a fully open-source, non-profit community project, built to make a better personal agent together, and it will never charge for anything.** Sign in with an e-mail address or a phone number and the agent has free model access, about ¥25 (≈ $3.5) a day per account: paid for by the developer. Your messages are not stored by the relay and nothing about you is sold or shared; delete the account at any time, or bring your own API key and skip the relay altogether.

## Added

- **Calls.** Tap the handset in the chat header and talk to your Muse the way you would call a person: it answers in its voice while you are still finishing, you can talk over it, and on a **video call** it sees what your camera sees. Same agent as the chat (its name, its personality, what it remembers about you) and what was said stays in the conversation. Runs on Alibaba's Qwen Omni real-time model through your account (metered like everything else, ¥ shown live) or straight to the provider with your own Bailian key. Phone, web and desktop. [docs/calls.md](../calls.md).
- **Your coding agents, from anywhere.** The Cursor, Codex and Claude Code sessions on your computer, seen and steered from the phone, the browser or another computer of your account: the agents installed and what is running, the recent sessions with their last exchange, a full transcript, and a composer, the message goes out, the answer streams back step by step, and a run can be stopped. Nothing is installed into the agents and nothing goes through anyone's server: the runtime on your computer reads what they leave on disk and starts their own CLIs. The Muse can do it too: "tell Codex in the api repo to add a test for the parser". [docs/coding-agents.md](../coding-agents.md).
- **The account, first.** Every app now starts with the sign-in (a code or, once you have set one, a **password**) and then asks which model answers: the account's own or a key of your own. The *Account* screen shows who is signed in and since when, sets, changes or removes the password, lists every device holding a key (each can be signed out), breaks usage down **by kind** (chat, pictures, video, calls) and **by model**, today and all time, shows the account's own history, and offers the three ways out: this device, everywhere, the account itself.
- **One design language.** The phone's look (a grey canvas, white cards, one action blue) on the web app, the desktop, the web console and the operator's page. The stage over the screen while the hands work is finer on both the desktop and the phone: a ring with a turning arc where a tap will land, ripples as it lands, a comet along a swipe, the step in a pill, and cheap enough for a machine without a GPU.
- **For whoever runs a relay:** the operator's page is now a dashboard (accounts, who was active, what it cost today / this week / this month by kind and by model, spend by day, the top spenders, today's signals, a timeline) with a drawer per account. Still never anyone's messages; a phone number is decrypted only when you open that account.

## Changed

- Picking a new look for the avatar no longer says it is ready the moment the request is accepted; the app says it is drawing and reports back when the pictures (or the clip) have landed.
- Android versionCode 21.

## Install

| | |
|---|---|
| Browser | [nanomuse.cn/web](https://nanomuse.cn/web/): an e-mail or a phone number |
| Android 8.0+, arm64 | `NanoLika-0.1.20-arm64.apk`: same signing key, installs over 0.1.19 (versionCode 21); `sha256sum -c NanoLika-0.1.20-arm64.apk.sha256` |
| Windows 10+ | `NanoLika-Desktop-0.1.20-win-x64.exe` (the app) · `nanomuse-desktop-terminal-0.1.20-windows-x64-setup.exe` (terminal) |
| macOS 12+ | `NanoLika-Desktop-0.1.20-mac-arm64.dmg` / `-mac-x64.dmg` (the app) · `nanomuse-desktop-terminal-0.1.20-macos-arm64.pkg` / `-x64.pkg` (terminal) |
| Linux x64 | `NanoLika-Desktop-0.1.20-linux-x64.AppImage` / `.deb` (the app) · `nanomuse-desktop-terminal-0.1.20-linux-x64.deb` / `.tar.gz` (terminal) |

The desktop installers are not code-signed: macOS asks for right-click → *Open* once, Windows for *Run anyway*. `SHA256SUMS-desktop-app.txt` and `SHA256SUMS-desktop-terminal.txt` list every checksum. The installers arrive a little after the APK: CI builds them from the tag.

给你的 Muse 打个电话。在口袋里指挥电脑上的 coding agent。一个账号、一套设计，在你的每一台设备上。

**NanoLika 是纯开源、非营利的社区项目，目标是和社区一起做出更好的个人智能体，永远不会收取任何费用。** 用邮箱或手机号登录，就能免费使用模型，现阶段每个账号每天约 ¥25（≈ $3.5），模型费用由开发者自己承担。中转不保存你的消息，你的任何数据都不会被出售或分享；随时可以删除账号，也可以直接用自己的 API key，完全不经过中转。

### 新增

- **打电话。** 点对话顶部的听筒，像给人打电话一样和你的 Muse 说话：你还没说完它就用自己的声音接上，你可以随时插话；**视频通话**时它能看到你的摄像头看到的东西。和聊天里是同一个智能体（名字、性格、记得的关于你的事），说过的话也留在对话里。模型是阿里云通义千问 Omni 的实时模型，走你的账号（和其他用量一样计费，费用实时显示），也可以用自己的百炼 key 直连服务商。手机、网页、桌面都有。[docs/calls.md](../calls.md)。
- **随时随地看你的 coding agent。** 电脑上 Cursor、Codex、Claude Code 的会话，在手机、浏览器或账号下另一台电脑上都能看、都能指挥：装了哪些、哪个正在跑、最近的会话和最后一轮对话、完整记录，还有一个输入框，消息发出去，回答一步步流回来，跑偏了可以停。不往 agent 里装任何东西，也不经过任何人的服务器：你电脑上的运行时读它们留在磁盘上的记录，启动它们自己的命令行。Muse 自己也会用，「让 api 仓库里的 Codex 给解析器加个测试」。[docs/coding-agents.md](../coding-agents.md)。
- **先登录。** 每个 App 现在都从登录开始，验证码，或者设过之后用**密码**，然后问一句由谁来回答：账号自带的模型，还是你自己的 key。「账号」页显示谁在登录、从什么时候起，设置、修改或移除密码，列出每一台持有登录的设备（每一台都能单独退出），用量**按类型**（对话、图片、视频、通话），和**按模型**分开统计，今天和累计各一份，还有账号自己的历史记录，以及三条退路：这台设备、所有设备、整个账号。
- **一套设计语言。** 手机版的样子（灰底、白卡片、一个动作蓝），搬到了网页 App、桌面版、网页控制台和管理后台。Hands 干活时盖在屏幕上的 stage 在桌面和手机上都更细了：即将点击处一个带旋转弧线的圆环、落下时的两圈涟漪、滑动时的一道彗尾、写着当前步骤的胶囊，而且在没有 GPU 的机器上也不卡。
- **给自己搭中转的人：** 管理后台现在是一块仪表盘，账号、谁活跃过、今天 / 本周 / 本月按类型和按模型花了多少、每日花费、花得最多的账号、今天的信号、时间线，每个账号一个抽屉。仍然不会有任何人的消息；手机号只在打开某个账号时才解出来。
