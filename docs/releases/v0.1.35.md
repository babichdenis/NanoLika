# NanoLika 0.1.35 · Accord

🐉 **NanoLika `0.1.35` “Accord”** brings the iPhone and the desktop to the phone's design, screen for screen. On the iPhone the Muse header (the face, the name, the live status line) sits on every room, Settings are the phone's cards in the phone's order, and a face you had drawn gets its four motion clips. The desktop meets you the way the phone does: the pages of the first run, then a first conversation where the app speaks first and asks what to call you, no more multiple-choice question about its name.

The other story is the small things that break trust: on a Mac the face did not react to clicks, Ideas was empty, the splash showed a dragon that may not be your Muse at all. All three are gone. And when the apps ask for a star on GitHub is no longer a constant in the code: the relay serves the policy, never in the first conversation; the 3rd task, a week in, a goal reached, and every client picks it up within a day, so the moments can change without an update. Every client also shows the version it is running next to the latest one.

## Highlights

- **The iPhone's chrome and settings after the phone's.** The Muse header (face disc, name pill, status line, round drawer and menu buttons) on the chat and on Feed, Ideas, Goals and Library; the side drawer after Android's; the agent's replies in Muse's grey bubble; the agent page's toolbar as round buttons. *Settings → NanoLika* rebuilt as Muse cards in the Android order: Image & video models, Avatar, Computers, Appearance (avatar size, the model under the name, the steps, the theme), Notifications, Account, Coding, Scheduled tasks, Shared folders, Chat files, System files, Version. A Notifications page joined the first run.
- **Motion clips on the iPhone and the desktop.** A drawn face gets four 4-second clips (idle, working, waiting, happy) from `wan2.2-i2v-flash` through the relay or your own Bailian key, the phone's prompts word for word; the face plays them where it is large enough. *Animate the avatar after a change* (on by default) and *Make / Redo clips* under Image & video models on the iPhone and Settings → Media on the desktop; the studio's cost estimate counts the clips.
- **The desktop's first run is the phone's.** Welcome, sign-in, a password, which model answers, models, the macOS permissions, Meet: kept by the host in `firstrun.json`, never skipped on a fresh install. Then the first conversation: the app speaks first (three scripted lines, no tokens), asks what to call you, and the model's `nanomuse-naming` block becomes the naming card. The multiple-choice `take_name` question is gone.
- **Three desktop bugs from the Mac.** The header face reacts to clicks on macOS and Windows again (the draggable region was computed from an untransformed box, so a centred header was all drag bar); Ideas is no longer empty when the bundle runs from `lib/chunks/`; the splash is the wordmark, a quiet loader and the person's own face when there is one, never the dragon.
- **Star asks from a policy.** The relay's `GET /v1/nudges` (public, cached an hour) and `nudges` in `/v1/me` say when the apps may ask: at sign-in, after the 3rd / 10th / 30th task, on the 7th / 30th day, when a goal is reached, after a new look, when the allowance is spent, seven days apart, four times per device at most. A *task* is a turn you started that got a reply: never the first conversation, never a routine, a feed post or a goal check-in. The operator edits the policy on the console (*Star asks*); every client (Android, iPhone, desktop, web) reads it once a day and keeps the same defaults built in.
- **Installed and latest, side by side.** *Settings → Version* on the phones, About and the Settings row on the desktop, Settings on the web: the version you run and the newest release, *Latest 0.1.x: you have it* / *0.1.x is out · Update* / *Could not check · tap to try again*. The check reads `nanomuse.cn/dl/index.json` first and GitHub second, once a day.
- **The Feed is never blank.** It opens on the phone's intro card with *Write it now*, says when the daily routine runs (08:00; adjustable), and writes its first day when the first conversation ends, on the desktop, the web, the iPhone and the phone alike. Memory, Skills and Devices on the web explain themselves while empty.
- **macOS permissions, re-audited.** macOS attributes the bundled runtime's captures and events to the app that started it, so only *NanoLika Desktop* has to be switched on under Accessibility and Screen Recording: the words say so now, and there is no second entry to hunt for. A restart dialog when Screen Recording flips on; a black-screen notice with *Relaunch*; *Try it* rows (a test screenshot, a mouse move) and the runtime row under Computer use and on the first run's permissions page. Window mode keeps `auto` as its default with a fail-safe: when the Quartz layer itself fails, the hands stay on the whole screen for that target and say so once.
- **Words.** A native-speaker pass over the nine README translations and the website; 104 more iPhone strings in 简体中文 and 繁體中文; the README says the iPhone app ships (TestFlight) and 0.2.0 is the App Store.

## Upgrade Notes

- **Android installs over 0.1.34 and keeps your data.** `NanoLika-0.1.35-arm64.apk` (Android 8.0+, arm64; versionCode 36) is signed with the same key as every version before it. Verify with `sha256sum -c NanoLika-0.1.35-arm64.apk.sha256`.
- **The star asks move.** The first ask after a task comes at the third, not the first, and never during the naming conversation; a device that was already asked keeps its ledger. If you run your own relay, Cloud 0.18.0 serves the policy (`/v1/nudges`, `/v1/admin/nudges`, the console's *Star asks* card); older relays are fine: the clients keep the defaults.
- **The desktop's first run shows once more** for installs that never finished it: the host now keeps `firstrun.json`, and an install without that file meets the pages (and the first conversation, when the agent has no name yet). *Help & support → See the first run again* reopens the pages on purpose.
- **Motion clips cost tokens like pictures do.** With a Cloud account the four clips count against the allowance (the estimate says how much before anything is drawn); with your own Bailian key they run on it. *Animate the avatar after a change* is on by default and can be switched off under Image & video models (iPhone) or Settings → Media (desktop).
- **macOS: still untried on a Mac by the maintainer** (the build machine is Linux), the permission words, the *Try it* rows, the restart dialog, window mode's clicks and Retina mapping follow Apple's documented behaviour; a report from a Mac decides what changes next. `[hands] mode = screen` is the whole-screen behaviour.
- **iOS is TestFlight-internal.** The composer and your own bubbles are still OpenMinis's; the header is fixed, not floating. Both are on the list.
- **The desktop installers are not notarised.** On macOS open the app once from *System Settings → Privacy & Security → Open Anyway* (or right-click → *Open*); on Windows click *Run anyway*. The checksum sits next to every file.

## Community

nanoMuse is open source and free. Sign in with a phone number or an e-mail and you get a starting allowance; the developer pays for it. The account page shows what is left and how to add more. When it is gone, use your own key: Alibaba Cloud Bailian in mainland China, OpenRouter elsewhere ([how](https://github.com/nano-muse/nanoMuse/blob/main/docs/own-key.md)). Messages are not stored by default and nothing is sold ([privacy policy](https://nanomuse.cn/privacy/)); delete the account whenever you want.

This is a preview. We use it every day and know where it is rough; tell us where it broke for you and what you want it to do. Thanks to everyone who tried a build and reported what broke. 🐉 **NanoLika `0.1.35`「Accord」**：把 iPhone 和桌面端按手机的设计逐屏对齐。iPhone 上每个房间都有 Muse 顶栏（形象、名字、实时状态行），设置是手机那套卡片、手机那个顺序，你画出来的形象有了四段动态短片。桌面端像手机一样和你见面：初次使用的几页，然后是第一次对话，应用先开口、问你怎么称呼，不再弹一道关于它名字的选择题。

另一条线是那些让人失去信任的小事：Mac 上点形象没反应、点子是空的、启动页上是一只未必是你的 Muse 的小龙。三个都没了。还有，什么时候提醒你给 GitHub 点 star 不再是写死在代码里的常量：中转下发策略，第一次对话里绝不提醒；第 3 个任务、用满一周、达成一个目标，每个端一天内读到，想改不用更新软件。每个端也都把正在运行的版本和最新版本并排显示。

### 亮点

- **iPhone 的界面和设置照着手机做。** Muse 顶栏（形象圆盘、名字胶囊、状态行、圆形的抽屉和菜单按钮）在聊天和动态、点子、目标、资料库上都有；侧边抽屉照 Android 的；智能体的回复用 Muse 的灰色气泡；智能体页面的工具栏是圆按钮。「设置 → NanoLika」重做成 Android 顺序的 Muse 卡片，图像与视频模型、形象、电脑、外观（形象大小、名字下方显示模型、步骤、主题）、通知、账号、编码、定时任务、共享文件夹、聊天文件、系统文件、版本。初次使用多了一页通知。
- **iPhone 和桌面端的动态短片。** 画出来的形象有四段 4 秒短片（待机、工作中、等你、开心），由 `wan2.2-i2v-flash` 经中转或你自己的百炼 key 生成，提示词和手机逐字相同；形象够大的地方就播放。「换形象后生成动态」（默认开）和「生成 / 重新生成短片」在 iPhone 的图像与视频模型里、桌面端的设置 → 媒体里；工作室的费用估算把短片算在内。
- **桌面端的初次使用就是手机的。** 欢迎、登录、密码、谁来回答、模型、macOS 权限、见面，由宿主记在 `firstrun.json` 里，新装绝不跳过。然后是第一次对话：应用先开口（三句写好的话，不花 token），问你怎么称呼，模型的 `nanomuse-naming` 块变成取名卡片。`take_name` 那道选择题没了。
- **Mac 上发现的三个桌面端问题。** 顶栏的形象在 macOS 和 Windows 上重新响应点击（可拖动区域是按未变换的盒子算的，居中的顶栏整条成了拖动条）；打包后从 `lib/chunks/` 运行时点子不再为空；启动页是字标、安静的加载指示和你自己的形象（有的话），绝不是小龙。
- **star 提醒走策略。** 中转的 `GET /v1/nudges`（公开，缓存一小时）和 `/v1/me` 里的 `nudges` 说明什么时候可以提醒：登录时、第 3 / 10 / 30 个任务后、第 7 / 30 天、达成一个目标、换了新形象、额度用完，间隔七天，每台设备最多四次。*任务*指你发起并得到回复的一轮：第一次对话、例行任务、动态帖子、目标打卡都不算。运维者在控制台（「Star 提醒」）编辑策略；每个端（Android、iPhone、桌面、网页），每天读一次，并内置同样的默认值。
- **已安装与最新版本并排。** 手机的「设置 → 版本」、桌面端的关于和设置行、网页版的设置：你运行的版本和最新的版本，「最新 0.1.x，你已是最新」/「0.1.x 已发布，更新」/「检查失败，点一下重试」。先读 `nanomuse.cn/dl/index.json`，再读 GitHub，一天一次。
- **动态不再空白。** 打开是手机的介绍卡，带「现在就写」，说明每天例程什么时候跑（08:00，可调），第一次对话结束就写第一天，桌面端、网页版、iPhone 和手机都一样。网页版的记忆、技能、设备在空着时说明自己是什么。
- **macOS 权限重新排查。** macOS 把内置运行时的截屏和输入归到启动它的应用名下，所以辅助功能和屏幕录制里只需要打开 *NanoLika Desktop* 一项，文案现在这么说，也不用再找第二个条目。屏幕录制打开时弹重启对话框；黑屏时有带「重新启动」的提示；「试一下」行（一张测试截图、一次鼠标移动）和运行时那一行在「电脑使用」里和初次使用的权限页上都有。窗口模式默认仍是 `auto`，加了保底：Quartz 层本身出错时，手在这个目标上退回整个屏幕并说明一次。
- **文字。** 九种 README 翻译和网站过了一遍母语者视角；iPhone 又多了 104 条简体和繁体中文；README 说 iPhone 应用已经在发（TestFlight），0.2.0 是 App Store。

### 升级说明

- **Android 覆盖安装 0.1.34，数据保留。** `NanoLika-0.1.35-arm64.apk`（Android 8.0+，arm64；versionCode 36）和之前每个版本用同一把签名。校验：`sha256sum -c NanoLika-0.1.35-arm64.apk.sha256`。
- **star 提醒的时机变了。** 任务后的第一次提醒在第三个任务、不是第一个，取名的那次对话里绝不提醒；已经提醒过的设备保留记录。自己跑中继的话，Cloud 0.18.0 下发策略（`/v1/nudges`、`/v1/admin/nudges`、控制台的「Star 提醒」卡片）；旧中继也没问题，各端用内置默认值。
- **桌面端的初次使用会再出现一次**，对那些从没走完它的安装：宿主现在记 `firstrun.json`，没有这个文件的安装会看到这几页（智能体还没名字时，还有第一次对话）。「帮助与支持 → 再看一次初次使用」可以主动重开。
- **动态短片和图片一样花 token。** 用 Cloud 账号时四段短片计入额度（画之前估算会说明多少）；用自己的百炼 key 时走你的 key。「换形象后生成动态」默认开，可以在图像与视频模型（iPhone）或设置 → 媒体（桌面端）里关掉。
- **macOS：维护者还没在 Mac 上试过**（构建机是 Linux），权限文案、「试一下」行、重启对话框、窗口模式的点击和 Retina 映射都照 Apple 文档的行为写；来自 Mac 的反馈决定下一步改什么。`[hands] mode = screen` 是整屏行为。
- **iOS 目前是 TestFlight 内部测试。** 输入框和你自己的气泡还是 OpenMinis 的；顶栏是固定的、不悬浮。都在清单上。
- **桌面安装包没有经过公证。** macOS 第一次在「系统设置 → 隐私与安全性」里点「仍要打开」（或右键 → 「打开」），Windows 点「仍要运行」。每个文件旁边都有校验值。
