# NanoLika 0.1.22 · Commons

Easier to trust, cheaper to run, simpler to join. The notice is up front everywhere, the allowance is ¥15 with cheaper models behind pictures and clips and a cost check before a face is drawn, invitations give both people more, sign-in is by e-mail, calls are gone and a microphone is back, and, only if you switch it on, your conversations can go towards a model the community trains itself.

**nanoMuse is a non-profit open-source community project: free, forever.** Sign in with an e-mail and use the model for free: about ¥15 a day per account, paid by the developer; invite a friend and you get ¥3 more. Messages are not stored unless you choose to contribute them; nothing is sold. Delete the account whenever you like, or use your own API key. Found a bug, want a feature, or wrote a fix? [Open an issue](https://github.com/nano-muse/nanoMuse/issues/new/choose) · [send a pull request](../../CONTRIBUTING.md) · [star the repo](https://github.com/nano-muse/nanoMuse): let's build it together.

## What changed

- **Invite a friend.** Every account has an invite code and a link (*Account → Invite a friend*). A friend who signs up with it gives you ¥3 of credit (spent once the day's ¥15 is used up, never expiring) and four more video clips. The sign-in form takes a code; the web app reads it from `nanomuse.cn/web/?invite=…`.
- **You see the cost before a face is drawn.** On the phone, changing the look (pictures or an animated face) first says what it will cost, what is left today and how many clips remain, and waits for your tap. The default models behind it are five times cheaper: `qwen-image-3.0` (¥0.18 a picture) and `wan2.2-i2v-flash` (¥0.50 a 5-second clip). Four clips per account, more with invitations.
- **Contribute conversations, off by default.** A switch under *Account* on the web, the phone and the console. On, the relay keeps each chat turn (what you sent, with pictures replaced by a marker; what came back; the token counts; the app's platform and language) for a training set for the community's own open model. Off, nothing is kept, as before. Turn it off and delete what you gave at any time; deleting the account deletes it too. The apps never send your location and the relay does not record IP addresses. [docs/privacy.md](../privacy.md).
- **Voice input, no calls.** The voice and video calls of the last two versions are gone: expensive to run for everyone and beside the point. In their place, a microphone next to *Send* on the web and the desktop that uses the browser's own speech recognition; the phone keeps the voice input it had.
- **The desktop app installs.** macOS: the app is signed ad hoc and ships as a zip and an APFS dmg, so dragging it out no longer fails with Finder error -36; Gatekeeper offers *Open Anyway* (System Settings → Privacy & Security) instead of "damaged". Windows: the runtime no longer tries to create its workspace in `System32` and stop with "the data folder is not writable"; it lives under `%USERPROFILE%\.nanomuse`. The failure dialogs speak the system language.
- **The notice, first.** README and the site open with it; the sign-in gate, *Settings → About* on the web and the account page on the phone carry it with *Star on GitHub* and *Report a bug or ask for a feature*.
- **A running light round the stage.** While the hands work, one light runs clockwise round the screen's edge, a bright head with a long tail, on the desktop and the phone alike: cheap enough for a 4K display without a GPU.
- **Everything follows the system language**, and the allowance is **¥15 a day**; sign-in is **by e-mail** (accounts made with a phone number keep working).

## Install

| | |
|---|---|
| Browser | [nanomuse.cn/web](https://nanomuse.cn/web/): an e-mail address |
| Android 8.0+, arm64 | `NanoLika-0.1.22-arm64.apk`: same signing key, installs over 0.1.21 (versionCode 23); `sha256sum -c NanoLika-0.1.22-arm64.apk.sha256` |
| Windows 10+ | `NanoLika-Desktop-0.1.22-win-x64.exe` (the app) · `nanomuse-desktop-terminal-0.1.22-windows-x64-setup.exe` (terminal) |
| macOS 12+ | `NanoLika-Desktop-0.1.22-mac-arm64.zip` / `-mac-x64.zip` (unzip, drag to Applications) or the `.dmg` (the app) · `nanomuse-desktop-terminal-0.1.22-macos-arm64.pkg` / `-x64.pkg` (terminal) |
| Linux x64 | `NanoLika-Desktop-0.1.22-linux-x64.AppImage` / `.deb` (the app) · `nanomuse-desktop-terminal-0.1.22-linux-x64.deb` / `.tar.gz` (terminal) |

The desktop installers are not notarised: on macOS open it once from System Settings → Privacy & Security → *Open Anyway* (or right-click → *Open*), on Windows click *Run anyway*. `SHA256SUMS-desktop-app.txt` and `SHA256SUMS-desktop-terminal.txt` list every checksum. The installers arrive a little after the APK: CI builds them from the tag.

### 变了什么

- **邀请朋友。** 每个账号都有邀请码和邀请链接（「账号 → 邀请朋友」）。朋友用它注册，你得到 ¥3 额度，当天 ¥15 用完之后才开始扣，永不过期，以及 4 段视频的额度。登录表单可以填邀请码；网页版会从 `nanomuse.cn/web/?invite=…` 直接读到。
- **换形象之前先看花费。** 手机上换形象（出图或者做动态形象），会先告诉你这次大约花多少、今天还剩多少、还能做几段视频，你点确认才开始。背后的默认模型便宜了五倍：`qwen-image-3.0`（¥0.18 一张）和 `wan2.2-i2v-flash`（5 秒一段 ¥0.50）。每个账号 4 段视频，邀请可以加。
- **贡献对话，默认关闭。** 网页、手机和控制台的「账号」里各有一个开关。打开后，中转会保留每一轮对话（你发的内容，图片替换成占位；模型的回复；token 数；App 的平台和语言），用于训练社区自己的开源模型。关闭时什么都不保存，和以前一样。随时可以关掉并删除已贡献的内容；删除账号时一并删除。App 从不发送你的位置，中转也不记录 IP 地址。[docs/privacy.md](../privacy.md)。
- **语音输入，不再打电话。** 前两个版本的语音/视频通话去掉了，给所有人跑太贵，也偏离了重点。取而代之的是网页和桌面版发送键旁边的麦克风，用浏览器自己的语音识别；手机保留原有的语音输入。
- **桌面版装得上了。** macOS：App 做了 ad hoc 签名，以 zip 和 APFS 格式的 dmg 发布，拖出来不再报 Finder 的 -36 错误；Gatekeeper 会给「仍要打开」（系统设置 → 隐私与安全性）而不是「已损坏」。Windows：运行时不再试图在 `System32` 里建工作区然后报「数据目录不可写」停掉；它现在在 `%USERPROFILE%\.nanomuse` 下。出错的弹窗跟随系统语言。
- **说明放在最前面。** README 和网站开头就是它；登录页、网页版「设置 → 关于」和手机的账号页也有，带「去 GitHub 点 Star」和「反馈问题 / 提需求」。
- **stage 四周的流光。** Hands 干活时，一道光沿屏幕边缘顺时针流动，亮头长尾，桌面和手机一样，没有 GPU 的 4K 屏也跑得动。
- **全部跟随系统语言**；额度 **每天 ¥15**；**邮箱登录**（用手机号注册过的账号照常可用）。
