# NanoLika 0.1.23 · Welcome

The version before we tell people about it. One allowance that lasts, and three ways on when it is spent; two short steps after a new account; the avatar studio on every device; a desktop app laid out like one; a computer that joins by signing in; a download mirror within reach of China; the operator seeing the whole picture; and a tidier front door on GitHub.

**Free, open source, non-profit: open source, built together: a personal agent for all.** Sign in with an e-mail and use the model for free: ¥10 per account, for good (it does not reset) plus ¥5 for each friend who signs up with your invite code and ¥10, once, for joining the co-creation programme; or use your own API key, with a step-by-step guide. Messages are not stored unless you choose to contribute them; nothing is sold; delete the account whenever you like. Report a bug, ask for a feature, send a pull request, every one brings a personal agent within everyone's reach. [Open an issue](https://github.com/nano-muse/nanoMuse/issues/new/choose) · [send a pull request](../../CONTRIBUTING.md) · [Discussions](https://github.com/nano-muse/nanoMuse/discussions) · [star the repo](https://github.com/nano-muse/nanoMuse).

## What changed

- **One pool, for good** (relay 0.5). The free allowance is **¥10 per account for its lifetime** instead of ¥15 a day: nothing is refused at midnight or for a count of clips. It grows by **¥5 for each new person who signs up with your invite code** and by **¥10, once, for joining the co-creation programme** (*Contribute conversations*, renamed and still off by default). Members have no limit. Existing accounts start with ¥10 on top of what they had.
- **When it is gone, three ways on.** The web, the desktop and the phone show a card under the refused turn and on the account page: your own key (Alibaba Cloud Bailian first, the provider form pre-filled and a step-by-step guide at [nanomuse.cn/own-key](https://nanomuse.cn/own-key)), an invitation, or the co-creation programme. At 80 % the account page says so ahead of time. Switching to your own key never touches the sign-in or the devices.
- **Two short steps after a new account.** A code sign-in that creates the account is followed by *Set a password* (so the next device signs in without a code) and *Join the co-creation programme?* (+¥10 once), both skippable, both under Account later.
- **The avatar studio on the web and the desktop.** 「换个形象：一只橘猫」 or "new avatar: a robot owl" in the chat (or *Settings → Draw a new one*) says the cost first, draws four candidates to pick from, then the four poses of the one you chose, and the new face is on everywhere. Pictures come from the chat model's host: the relay, any OpenAI-compatible provider, or Alibaba Cloud Model Studio through its native endpoint; `[llm] image_model` / `video_model` choose the models, *Automatic* by default. Without an image model the chat says so instead of trying.
- **The web app wears the blue N**, and the dragon is the only drawn face: the red panda and the six dolls are gone (a profile that still names one wears the dragon), next to a face from the studio and the emoji.
- **The desktop app lays itself out like one.** The sidebar is there at every window width and the content runs across the window; on a Mac the sidebar starts below the traffic lights and drags the window. Connections → Model gains *Pictures and clips*. When the runtime does not start, the dialog waits longer (120 s on Windows), quotes this session's log only, and offers *Copy details* and *Open the log folder*.
- **A computer joins by signing in, not by script.** *Settings → Computers* on the phone leads with: install NanoLika Desktop, sign in with the same account, and the computer is under *Account → Devices* within seconds, on any network. The local-network host script is the fallback. The desktop app says once, when it first reaches the hub, that the phone can now operate this computer.
- **The stage, the same on both.** One comet in three hues (blue into violet into cyan) round the screen on the desktop and the phone alike, amber while the hands wait for you; the phone's capsule is the desktop pill.
- **A download mirror in reach of China.** [nanomuse.cn/dl/](https://nanomuse.cn/dl/) keeps the newest two releases, every file checked against GitHub's SHA-256, and the site's download list has a switch (GitHub or the mirror) that a browser in Chinese starts on.
- **The operator sees the whole picture** (relay 0.5.1). Two panels on the admin page: the relay's numbers by day with the devices, the invite funnel and NanoLika Web's counts; and the site's visits and downloads, counted by day from the access log with no addresses stored: a visitor is a salted hash for the day. The samples export downloads again.
- **The notice, said as a slogan and put first**, in both READMEs, on the site and behind every app card; **GitHub Discussions** is open; the README badges cover Web, Android, Windows, macOS, Linux and Docker.
- **Coding agents, three small things.** `running` counts on macOS and Windows too; the record of runs survives a restart of the runtime; a Cursor chat made in the IDE continues as a new chat in the same workspace with the last exchange quoted, and the apps say so.

## Install

| | |
|---|---|
| Browser | [nanomuse.cn/web](https://nanomuse.cn/web/): an e-mail address |
| Android 8.0+, arm64 | `NanoLika-0.1.23-arm64.apk`: same signing key, installs over 0.1.22 (versionCode 24); `sha256sum -c NanoLika-0.1.23-arm64.apk.sha256` |
| Windows 10+ | `NanoLika-Desktop-0.1.23-win-x64.exe` (the app) · `nanomuse-desktop-terminal-0.1.23-windows-x64-setup.exe` (terminal) |
| macOS 12+ | `NanoLika-Desktop-0.1.23-mac-arm64.zip` / `-mac-x64.zip` (unzip, drag to Applications) or the `.dmg` (the app) · `nanomuse-desktop-terminal-0.1.23-macos-arm64.pkg` / `-x64.pkg` (terminal) |
| Linux x64 | `NanoLika-Desktop-0.1.23-linux-x64.AppImage` / `.deb` (the app) · `nanomuse-desktop-terminal-0.1.23-linux-x64.deb` / `.tar.gz` (terminal) |

In China, the same files from [nanomuse.cn/dl/v0.1.23/](https://nanomuse.cn/dl/v0.1.23/). The desktop installers are not notarised: on macOS open it once from System Settings → Privacy & Security → *Open Anyway* (or right-click → *Open*), on Windows click *Run anyway*. `SHA256SUMS-desktop-app.txt` and `SHA256SUMS-desktop-terminal.txt` list every checksum. The installers arrive a little after the APK: CI builds them from the tag; the mirror follows within fifteen minutes.

### 变了什么

- **一份额度，永久有效**（中转 0.5）。免费额度从「每天 ¥15」改为**每个账号终身 ¥10**：不会在半夜归零，也不再按视频段数拒绝。**每有一位新用户用你的邀请码注册 +¥5**，**加入共创计划一次性 +¥10**（原「贡献对话」，仍默认关闭）。社区成员不限量。已有账号在原有基础上多得 ¥10。
- **用完之后，三条路。** 网页、桌面和手机会在被拒的那一轮下面和账号页里给出一张卡：用自己的 key（优先阿里云百炼，服务商表单已经填好，教程在 [nanomuse.cn/own-key](https://nanomuse.cn/own-key)）、邀请朋友，或加入共创计划。用到 80% 时账号页会提前提醒。换成自己的 key 不影响登录和设备。
- **新账号之后的两个小步骤。** 验证码登录建好账号之后，接着是「设个密码」（下一台设备不用再收验证码）和「加入共创计划？」（一次性 +¥10），都可以跳过，之后在「账号」里也能做。
- **网页和桌面版的形象工作室。** 在对话里说「换个形象：一只橘猫」，或「设置 → 画一个新的」，先告诉你要花多少，画四张候选让你挑，再画你选的那张的四个姿态，新形象随处生效。图片来自对话模型所在的服务商：中转、任何 OpenAI 兼容服务商，或阿里云百炼的原生接口；`[llm] image_model` / `video_model` 选模型，默认「自动」。没有图片模型时，对话会直接说明，而不是白试一次。
- **网页版换上蓝色的 N**，画出来的形象只剩小龙，小熊猫和六个玩偶去掉了（还写着旧名字的档案会戴上小龙），旁边是工作室画的脸和 emoji。
- **桌面版真正像桌面软件了。** 任何窗口宽度下侧栏都在，内容铺满窗口；Mac 上侧栏从红绿灯下面开始，那一条可以拖动窗口。「连接 → 模型」多了「图片与视频」。运行时起不来时，弹窗等得更久（Windows 上 120 秒），只引用这次的日志，并提供「复制详情」和「打开日志文件夹」。
- **电脑登录即接入，不用脚本。** 手机的「设置 → 电脑」现在先说：装 NanoLika 桌面版，登同一个账号，几秒之后电脑就在「账号 → 设备」里，任何网络都行。局域网脚本退为备用。桌面版第一次连上 hub 时会说一次：手机现在可以操作这台电脑了。
- **两端一样的 stage。** 屏幕四周一道三色流光（蓝、紫、青），桌面和手机一致，Hands 等你时变成琥珀色；手机上的胶囊就是桌面版的 pill。
- **国内可达的下载镜像。** [nanomuse.cn/dl/](https://nanomuse.cn/dl/) 保留最新两个版本，每个文件都对过 GitHub 的 SHA-256；官网下载区多了一个切换（GitHub 或镜像），中文浏览器默认走镜像。
- **运营者看得到全貌**（中转 0.5.1）。管理后台多了两块：中转自己按天的数字，加上设备、邀请漏斗和网页版的数量；以及官网的访问与下载，从访问日志按天统计，不存任何地址，访客只是当天加盐的哈希。样本导出也修好了。
- **说明改成一句口号并放到最前面**，在两份 README、官网和每个 App 的卡片背后；**GitHub Discussions** 已开放；README 徽章覆盖网页、Android、Windows、macOS、Linux 和 Docker。
- **编程助手的三处小修。** macOS 和 Windows 上也能数进程了；运行记录在运行时重启后还在；IDE 里开的 Cursor 对话会在同一工作区开新对话接着说，并带上上一轮，App 里会说明。
