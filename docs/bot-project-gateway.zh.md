# 客户机器人网关

仅已付费且包含跨设备连接的有效套餐可使用网关。基础套餐、充值和赠送余额不会开通连接。到期暂停网关，不删除客户项目；AI 余额与连接期限分别检查。

代码、凭据及持久收件箱位于客户设备或客户自选云。中继仅保存项目元数据和凭据摘要；令牌与消息只在内存中转。必须保持本地处理进程运行，不承诺全天托管、自动启动、二进制上传或 Mini App 托管。平台账号和频道管理权限由所有者授权。

俄罗斯服务器已部署增量网关；桌面源码已接入工具，但未构建或安装应用。测试收单不会激活真实套餐。正式收单结算与订阅激活尚待接入。俄罗斯服务器直连 Telegram API 超时，新客户网关仍需显式配置里加传输路径，并使用独立机器人完成端到端验收。现有主机器人的正常运行不能证明新路径可用。

验证：49 项本地测试、43 项网关与支付测试、25 项桌面隔离测试通过，TypeScript 类型检查通过。完整说明参见 bot-project-gateway.md。
