# NanoLika 品牌

应用采用网站已经确认的暖纸色和鼠尾草绿风格。

## 标志 {#the-mark}

启动图标、启动页和登录页使用象牙白底上的精灵翅膀。
源文件是 `assets/brand/nanomuse-mark.svg`，`nanomuse-icon.svg` 添加底板。
为保持打包兼容性，历史文件名保留，原来的蓝色 N 图案已被替换。
聊天头像使用网站中的完整 Lika 精灵，鞋子和翅膀都保留在圆形区域内。
内部形象标识仍是 `dragon`，现有账号、表情形象、工作室形象和个人视频继续可用。

## 颜色 {#colour}

| 用途 | 浅色 | 深色 |
|---|---|---|
| 背景 | `#F7F1E6` | `#242820` |
| 卡片 | `#FBF6EC` | `#2D3229` |
| 次级背景 | `#EEE7D9` | `#363C31` |
| 正文 | `#38372F` | `#F7F1E6` |
| 次要文字 | `#66675B` | `#B8BEAC` |
| 操作和用户气泡 | `#52694E` | `#B3CBA5` |
| 操作上的文字 | `#FBF6EC` | `#242820` |
| 分隔线 | `#D8D1C1` | `#505847` |

珊瑚色和琥珀色只用于少量插画和状态细节。控件与长对话保留易读的系统或无衬线字体。
出厂默认采用浅色纸张主题，用户已保存的浅色、深色或跟随系统设置优先。
桌面使用现有的 `ui-theme` 设置，出厂偏好为浅色。
手机默认值由 `scripts/nanolika_theme.py` 生成，`rebrand.py` 会调用它。
网页语义色值在 `web/src/index.css`，桌面色值在 `styles.ts`。

## 资源与重新生成 {#assets-and-regeneration}

源图片和无声短片在 `assets/brand/avatar/`。短片采用 H.264 MP4。
小尺寸、出错、视频不可用或减少动态效果时使用静态图。状态时序和个人资料入口保持原有行为。

`python scripts/sync-brand.py` 重新生成图标并同步 Android、iOS、桌面插件和网页资源。
随后运行 `cd web && npm run build`，生成的运行时网页资源也需提交。
渲染器使用已有的 Node/Sharp，可通过 `NANOLIKA_NODE` 和 `NANOLIKA_SHARP_MODULE` 指定现有工具链，不会安装软件。
旧标志方案和没有引用的上游 iOS 图标变体已移除。
历史文档截图及第三方和上游署名资源保留，不能视为当前应用标识。

## 验证与清理 {#verification-and-cleanup}

`tests/test_brand_assets.py` 检查各客户端打包的形象资源是否与源文件一致。
旧龙形视频和封面图片一起被替换。旧标志方案 PNG 和没有引用的 `Icon-full*.png`
iOS 候选文件已移除，普通界面图标、第三方署名和历史截图保留。
Vite 构建会移除旧的带哈希网页文件。
网页 lint、类型、测试和生产构建已通过；桌面插件构建、类型与测试及桌面壳类型检查已通过。
手机主题生成已验证幂等。本机没有 Java/Android 工具链和完整 Xcode，未运行手机原生构建。
