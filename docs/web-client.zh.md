# nanoLika 浏览器客户端 / PWA

入口 `https://nanolika.ru/web/` 转至 `https://cloud.nanolika.ru/web/`。源码位于 `cloud/nanomuse_cloud/web_client`，无需构建原生安装包，必须使用 HTTPS。清单和 Service Worker 仅作用于 `/web/`。

首版提供现有 Cloud 邮箱验证码/密码登录、流式聊天、停止、对话导出/删除、本地文档库、中英俄界面和离线应用外壳。不提供电脑控制、发布、后台任务或个人网盘连接，也不公开桌面运行时 `/api`。本地文档不会自动成为模型附件。

对话列表中的每一行都标明它保存在哪里：有云朵表示 nanoLika Cloud 保存着它，账号的其他设备也能看到；带斜线的云朵表示仅此副本在本机。在本浏览器创建的对话可以移出云端，中继上的副本被删除，本机副本保留，之后也能用新的对话 id 放回云端。从其他设备或信使传来的对话不能改为本地对话，对其只能从云端彻底删除，确认方式与普通删除相同。请求被拒绝时，通知栏用界面语言给出简短提示。

消息会临时发送给 Cloud 和模型提供商以生成回复。对话及文件 Blob 按账户 ID 保存在设备的 IndexedDB 中，退出仅隐藏该账户数据，明确删除才清除。浏览器清理/隐私模式可能删除文件，应下载重要资料。同一浏览器配置中的本地数据不是加密保险箱。会话密钥只保留在浏览器，不进入 URL、缓存或应用日志。

请求携带 `store:false`，即使账户在其他客户端选择贡献样本，Cloud 也不保存此请求的训练样本。计费元数据仍然存在；此标志不代表不经过提供商或保证其保留策略。文档库没有上传请求，模型无法读取库内文件。

Service Worker 只缓存固定公开资源，不处理 POST、带鉴权的 GET、跨域或 `/v1/` 请求。离线仅能查看本地对话/文件，不能调用模型。静态页配置同源 CSP、no-referrer 和 nosniff。模型内容通过纯文本显示，不执行 HTML。

验证包含 SSE 分块、语言键一致性、Cloud 私有请求与静态路由、浏览器登录/文件不上传/离线/账户隔离及 390/768/1440 布局。部署前运行无网络 canary，并保留支付退款和网关覆盖层，不能用新源码整体替换旧线上 API 或自动开启正式收款。
