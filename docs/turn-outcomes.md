# Итоги незавершённых ходов

Desktop сохраняет последние 100 итогов в локальном cloud.json. Над полем ввода открытой беседы показан последний итог именно этой беседы: причина остановки, категория последней операции, число результатов без ошибки инструмента и число ошибок. Карточка не делает платного запроса и не запускает работу повторно. Это локальная служебная карточка, а не синхронизируемое сообщение модели.

Причины: лимит времени/шагов; два одинаковых ошибочных вызова подряд; ошибка; прерывание; завершение без итогового ответа после инструментов. Общая отмена не приписывается человеку. Успех инструмента не считается доказательством выполнения задачи. Сохраняются только категории, счётчики, идентификаторы и время; содержимое файлов, аргументы и текст ошибок не копируются.

Два одинаковых вызова с isError=true без успешного результата между ними останавливают текущий ход. Изменение аргументов или успешный результат сбрасывают серию. Ошибки, замаскированные инструментом как успешный результат (например, неверный exit code shell pipeline), не распознаются. Новая попытка выполнения задачи требует явного действия пользователя.

Правила объяснять неудачу, менять подход и завершать ответ конкретным итогом добавлены в preset и к запросам пользовательских сессий через llm/stream. Побочные генерации заголовков и сжатия не затрагиваются. Раскрытие внутренних рассуждений не требуется.

После установки учёт начинается с новых turn/start; старые логи не переписываются. Карточки относятся к desktop; серверный/web-контур требует отдельного подключения. При аварийном завершении процесса до turn/end итог не создаётся. Проверки — tests/turn-outcomes.test.mjs и tests/turn-budget.test.mjs.

Видимые пояснения действий, краткие сводки рассуждений, объяснения ошибок и итоги должны быть на языке пользователя; для русскоязычного пользователя — простым русским, даже когда инструменты возвращают английский текст. Скрытые внутренние рассуждения не раскрываются.
