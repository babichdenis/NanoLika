# 消息平台菜单与对话权限

Telegram 和 MAX 提供 /menu、/permissions、/balance、/pay、/language。付款打开网站，不在链接中携带账户密钥。余额来自当前认证账户，测试入账单独处理。回复语言按对话保存，支持俄语、英语及简体中文。群聊不显示余额或私人权限。菜单操作使用绑定平台、聊天及发送者的短期一次性票据，仅配对所有者或明确授权的身份可更改。

完全访问需要单独确认，随后不再逐步询问，但不能绕过明确禁止规则、系统权限、工具路径边界或主机管理员权限。在工作目录中写入会检查真实路径及符号链接，其他操作仍需确认。本地只读模式拒绝修改和任意代码执行；其他对话不受影响。正在执行的工具不会被权限变更自动中断。

桌面源码新增可选 channel_permissions 操作，使用应用内已有的对话权限预设。旧客户端无法确认应用权限时，中继明确说明需要更新，不以静默忽略代替成功。用户可选择沿用应用设置。此次未构建或安装原生应用。

运行中的两种消息渠道均已部署菜单并连接。银行托管页面的 200 RUB 测试卡付款已确认，仅测试钱包入账，真实额度未改变；临时身份及密钥已停用。正式收单仍未启用。详见 messenger-menu.md。
