# Ошибки, которые надо починить

Сюда пишем всё, что сломалось, — по одной записи, с датой и доказательством. Собираем, чтобы
чинить пачкой, а не на ходу.

## Формат записи

```
### ГГГГ-ММ-ДД · короткое имя
- **Что видно:** что человек или я заметили (симптом, текст ошибки).
- **Где:** файл, строка, сервис, страница.
- **Доказательство:** отчёт, лог, команда, ответ сервера.
- **Похоже на:** предполагаемая причина (если есть).
- **Статус:** не начато / смотрю / починено (коммит).
```

## 2026-10-25 · Сессия падает, приходится перезапускать приложение

- **Что видно:** во время работы сессия обрывается; приложение перезапускают руками. В
  `desktop.log` 56 записей «quit: the exit did not go through the protected exit».
- **Где:** рантайм (Python), `nanomuse/memory/store.py` — sqlite-соединение с
  `check_same_thread=False`.
- **Доказательство:** системный отчёт macOS
  `~/Library/Logs/DiagnosticReports/Python-2026-10-25-121852.ips`:
  `EXC_BAD_ACCESS (SIGSEGV)`, стек `pysqlite_connection_close → lru_cache_dealloc → take_gil`.
  То есть падение при закрытии соединения, из чужого потока, без трейсбека.
- **Похоже на:** sqlite закрывается не из того потока, где открыт; `lru_cache` держит объект
  дольше соединения и освобождается во время `take_gil`.
- **Статус:** не начато (решили сначала понаблюдать).
