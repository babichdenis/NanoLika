Образ Лики у клиентов

Меняется только стандартная Лика. Личные образы и клипы остаются у владельцев. Поддержка должна быть включена в версии приложения клиента.

Добавить набор

ZIP: manifest.json с названием label, пять WebP 768×768 и четыре беззвучных H.264 MP4 512×512. Названия: idle, working, waiting, happy, error; для error клип не нужен. Клип от 10 до 15 секунд.

Загрузка не меняет активный образ. Для смены нажмите «Показать клиентам» у нужного набора. Приложения получают обновление при следующей проверке, обычно в течение минуты. Без сети сохраняется встроенная Лика.
