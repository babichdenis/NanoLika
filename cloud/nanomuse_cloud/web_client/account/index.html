Связанные аккаунты

Ключ nanoLika API

Используйте ключ в своих приложениях. Запросы расходуют общий баланс аккаунта. Полный ключ показывается один раз.

Адрес API: https://cloud.nanolika.ru/v1

Скопируйте ключ сейчас и сохраните в надёжном месте. Позже его нельзя будет посмотреть снова.

Свои ключи

Подключите свой ключ провайдера — запросы пойдут через него и не будут тратить баланс nanoLika. Провайдеру платить всё равно придётся.
